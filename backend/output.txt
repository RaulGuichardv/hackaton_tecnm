1. REGISTRAR TRABAJADOR

--------------------------------------------------------------------

Método: POST

Ruta: /trabajadores/registrar

Código HTTP: 201 Created



Respuesta JSON:

{

  "mensaje": "Trabajador registrado exitosamente",

  "id_trabajador": 1

}

4. OBTENER ESTADO DEL TRABAJADOR

--------------------------------------------------------------------

Método: GET

Ruta: /trabajadores/{id_trabajador}/estado

Código HTTP: 200 OK



Respuesta JSON:

{

  "id_estado": 1,

  "estado": true

}





5. OBTENER DATOS DE EMERGENCIA DEL TRABAJADOR

--------------------------------------------------------------------

Método: GET

Ruta: /trabajadores/{id_trabajador}/datos-emergencia

Respuesta JSON:

{

  "id_datos_emergencia": 1,

  "nombre": "Maria Gomez (Esposa)",

  "telefono": "9611234567"

}

8. ACTUALIZAR TRABAJADOR (PARCIAL)

--------------------------------------------------------------------

Método: PATCH

Ruta: /trabajadores/actualizar/{id_trabajador}

Código HTTP: 200 OK



Respuesta JSON:

{

  "mensaje": "Trabajador 1 actualizado correctamente"

}





9. ACTUALIZAR VIGENCIA DEL TRABAJADOR

--------------------------------------------------------------------

Método: PUT

Ruta: /trabajadores/{id_trabajador}/vigencia

Código HTTP: 200 OK



Respuesta JSON:

{

  "fecha_inicio": "2026-01-01T00:00:00",

  "fecha_vencimiento": "2026-12-31T23:59:59"

10. ELIMINAR TRABAJADOR

--------------------------------------------------------------------

Método: DELETE

Ruta: /trabajadores/eliminar/{id_trabajador}

Código HTTP: 200 OK



Respuesta JSON:

{

  "mensaje": "Trabajador 1 y sus registros relacionados fueron eliminados exitosamente"

}
